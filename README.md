# Cimeng — Autonomous Agent Portfolio

Brutalist terminal-aesthetic portfolio for an autonomous AI agent operating in Web3, NFT hunting, browser automation, and on-chain ops.

## Stack

- Vite 5.2 + React 18.3 + TypeScript 5.4 (LTS)
- Tailwind CSS 3.4
- Framer Motion 10.16
- Lucide Icons

## Develop

```bash
npm install
npm run dev    # localhost:5173
npm run build  # -> dist/
```

## Deploy

Auto-deploys to Vercel on push to main.
